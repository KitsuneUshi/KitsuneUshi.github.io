// 學習紀錄 · 啟蒙

LEGO EV3 啟蒙

五歲開始的機器人課程，是我走向機械整合程式設計的起點。同樣的零件，不同的深度。

// 那時候的我

大約五歲的時候，我開始上 LEGO MINDSTORM EV3 的機器人課程。當時用樂高官方的積木式程式設計軟體，把一個個程式區塊堆疊起來，組成完整的控制邏輯。

那時候其實不太懂自己在做什麼，但只要機器人照著自己設計的程序動起來，就會有一種說不清楚的成就感。那種感覺很特別——不是別人告訴你答案，而是你自己的指令讓一件事情發生了。

課程全部上完之後，我還是一而再地重複報名，只是為了繼續待在那個喜歡的環境裡。

// 學到什麼

回頭來看，EV3課程教會我的不是某個具體的技術，而是一種思維方式——把一個目標拆解成一步一步的指令，然後自己設計機器執行。這其實就是設計一個完整的系統最核心的概念。

// 對現在的影響

從 EV3 到現在寫 C++、做 LLM 專案，表面上跨度很大，但那個最初的感覺從來沒有變過——用自己的邏輯讓東西運作起來，就是我持續走在這條路上的原因。

// 從啟蒙到應用

五歲時用 EV3 讓機器人動起來，那時只是覺得好玩；高三時再次拿起 EV3，卻是為了設計一套物理實驗裝置——以齒輪組加速馬達、控制撞擊桿打飛細桿，探討旋轉拋體的運動規律。

同樣的零件，不同的深度。五歲的我不懂齒輪比，只知道機器人會動了；高三的我用 EV3 的 Large Motor 搭配 40:8 齒輪組計算轉速，再把數據帶進轉動力學公式裡驗證理論。

這大概就是學習的樣子——起點看起來只是玩，但那個「讓東西動起來」的執念，一直都在。
