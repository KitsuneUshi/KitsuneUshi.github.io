// 備考過程

升上高一的暑假，我開始系統性地準備 APCS。主要透過寰宇教育中心 Let's Code 的課程（後來老師另創資電資訊教育，我也持續跟著上課）打好基礎，並在 ZeroJudge 上自行刷題練習。

遇到不會的題目時，除了直接問老師，也會去 HackMD、CSDN 找解題思路，或搜尋開放式課程。查英文資料的過程中，意外也訓練了英文聽力——尤其是印度口音。

備考最困難的地方是：很多題目很難直接想到解法，需要大量練題才能培養出對演算法與資料結構的直覺與靈活運用。

// 學到什麼

考完之後，我覺得自己進步最多的地方有兩個：一是掌握了更多資料結構與演算法的應用，二是透過觀念題的訓練，讀懂複雜程式碼的能力明顯提升了。

印象最深的是某次解題時，突然發現資料種類只有 26 個英文字母，靈機一動用了 Counting Sort 大幅加速——那瞬間的感覺很開心，也讓我理解到演算法的選擇要看資料的特性，不是套公式。

// 給未來想考 APCS 的人

最重要的是清楚自己的目標。想考幾級分，就知道要練到什麼程度——是專注語法、資料結構，還是進階演算法。沒有目標就容易練得很散，白費力氣。
