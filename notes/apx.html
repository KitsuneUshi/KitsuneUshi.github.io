// 備考過程

我參加過兩次 APX，分別是升高一下與升高二下的暑假。數學與物理都沒有特別準備，主要靠平時上課的知識與講義題目維持手感。

數學與物理相比，數學較難準備，因為題目更變幻莫測，難以預測考點方向。第二次數學中高未通過，主要是高三數甲下的內容較不熟悉，尤其是二次曲線這個區塊，掌握度明顯不足。

物理方面最吃力的是氣體動力論與光學，這兩個主題的題目寫起來很吃力，需要更多練習才能應對。

// 學到什麼

第二次考試給了我印象最深的一課：因為沒有特別背公式，考場上我必須臨場推導——用質心運動推導彈性碰撞公式、用積分推導簡諧運動公式、用勞倫茲力推導質譜儀半徑。

那次經驗讓我發現，真正理解觀念比死背公式更有用。雖然最後差 1.5 分與銅牌擦身而過，但從第一次未通過到幾乎摘牌，這個進步已經說明了很多事。

// 下次目標

如果有機會再考，目標是挑戰數學高級與物理高級。這次的經驗告訴我，若能在紮實理解觀念的基礎上加上充分準備，應該能拿到更好的成績。
