旋轉拋體實驗
物理專題

以 LEGO MINDSTORM EV3 為實驗裝置，探討剛體旋轉拋體質心位置與支點距離對最大飛行高度的非線性影響，並以平行軸定理建立數學模型驗證實驗結果。

年份 2026 類型 物理專題報告
Physics LEGO EV3 剛體力學 LaTeX DaVinci Resolve

組長・實驗設計・數據分析・報告編排・LaTeX 排版

// 01 · 背景

研究動機

高二進階物理課程中，授課教師向我們展示了學長的科展作品，讓我開始思考：能不能自己設計一套實驗系統來探究物理現象？於是我們決定以最熟悉的樂高零件與 LEGO MINDSTORM EV3 作為實驗裝置的核心，設計出一套可重複、可控制的旋轉拋體實驗系統。此專案直至高三下才開始執行。

// 02 · 架構

實驗設計

操縱變因 · 量測

質心位置與飛行高度

操縱細桿凸出平台的長度（12、18、24、30mm），以 LEGO EV3 Large Motor 透過兩組 40:8 齒輪組加速，驅動撞擊桿打飛均勻細桿，並以攝影機逐幀記錄。以 DaVinci Resolve 逐格追蹤質心，量測最大飛行高度。

理論模型 · 推導

平行軸定理

引入平行軸定理推導質心速度公式，以變量係數比較法分析理論與實驗的下降趨勢是否吻合。算式以 LaTeX 排版確保學術嚴謹度。

// 03 · 角色

我的貢獻與挑戰

身為組長，我負責實驗設計與數據分析整合，過程中遭遇四個主要挑戰。

第一，裝置穩定性不足——馬達轉速不穩定導致每組數據差異較大，需重複多次取樣以確保可靠性及穩定性。第二，BrickLink Studio 的虛擬建模與實際裝置之間存在落差，實體裝置需要反覆校調才能讓細桿正常起飛。第三，室內交流電燈頻閃導致慢動作畫面亮暗閃爍，在 DaVinci Resolve 逐格追蹤質心時造成困難，多組數據因此刪除。第四，為了建立理論模型，必須自學大一級別的轉動力學，包括轉動慣量與平行軸定理。

最有成就感的時刻有兩個：一是不斷校調裝置後，細桿終於能穩定正常起飛的瞬間；二是利用變量係數比較法計算下降趨勢時，看到實驗值幾乎符合理論預測的那一刻。

// 04 · 成果

實驗結果

實驗趨勢線與理論值高度吻合，驗證了數學模型的有效性。四組數據的飛行高度分別為 328.54mm、281.16mm、258.66mm、38.44mm，呈現非線性下降趨勢，符合理論預測。

最大飛行高度

328mm

凸出長度 12mm 時

四組結果：328.54 → 281.16 → 258.66 → 38.44mm，呈非線性下降，符合理論預測。

最小飛行高度

38mm

凸出長度 30mm 時

質心越靠近支點，衝量幾乎全轉為角動量，細桿原地旋轉而非向上起飛。

// 05 · 反思

學習收穫

歷經高一兩次探究與實作的累積，再到高三重新著手實驗專題，能明顯感受到實驗規劃能力的成長——從設計變因、控制誤差到建立理論模型，整體流程更加嚴謹。

這次最大的突破是面對虛擬建模與實際狀況落差的處理能力，學會在理想化的理論與充滿變數的實驗現實之間找到平衡點。這種「從不完美的數據中找出真實規律」的能力，我相信對往後無論是設計專案或實作研究，都會是很重要的基礎。
